# TCP Three-Way Handshake Analysis

## Objective
Capture and analyse TCP traffic using Wireshark.

## Tasks Completed
- Captured network traffic.
- Identified TCP SYN packets.
- Identified SYN-ACK responses.
- Identified ACK packets.
- Examined TCP connection establishment.

## Tools Used
- Wireshark

## What I Learned
I learned how TCP establishes connections through the SYN, SYN-ACK and ACK packet exchange.
