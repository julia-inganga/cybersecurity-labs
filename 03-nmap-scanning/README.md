# Nmap Port Scanning

## Objective
Understand port scanning and identify open ports on my own lab machine.

## Tasks Completed
- Performed TCP port scanning.
- Conducted SYN scans.
- Identified open ports.
- Compared different Nmap scanning techniques.

## Tools Used
- Kali Linux
- Nmap

## What I Learned
I learned how to use Nmap to identify open ports and understand the difference between SYN scans and full TCP connection scans.
