# Cybersecurity Labs

Hands-on practicals from my cybersecurity training with ALX Africa and IBM, documented as I work toward a SOC Analyst role.

## Why this exists
To practice core defensive and offensive security skills in a safe environment and show how I approach each task.

## Labs
| # | Lab | What I did | Tools |
|---|-----|-----------|-------|
| 01 | Kali Linux and virtual networking | Installed Kali in VirtualBox, configured a static IP, DNS and subnetting, then verified connectivity | Kali Linux, VirtualBox |
| 02 | TCP three-way handshake | Captured traffic and identified the SYN, SYN-ACK and ACK packets | Wireshark |
| 03 | Port scanning | Ran port and SYN scans against my own lab machine to see open ports | Nmap |

## What I learned
-Kali Linux and virtual networking: Learned how to configure a virtual machine's network settings, assign a static IP address, configure DNS and verify network connectivity.

-TCP three-way handshake: Learned how TCP establishes a reliable connection through the SYN, SYN-ACK and ACK packet exchange using Wireshark.

-Port scanning: Learned how to use Nmap to identify open ports and understand the difference between SYN scans and full TCP connection scans on my lab machine.

## ⚠️ Safety note
All scans were run only on machines I own or have permission to test, inside an isolated lab network.
